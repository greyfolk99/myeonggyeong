# 명경(明鏡) · 나의 사주

생년월일시 → fate-js로 계산 → **1차: 짧은 핵심 리딩(자동)** → **2차: 궁금한 장만 골라 깊이(요청 시)** → 전체 HTML 파일은 원할 때만.

## 0. 원칙 (위반 금지)

- 시트에 없는 사실을 지어내지 않는다. 모든 해석 문장은 계산된 팩트에 근거한다.
- 대운·세운·연도별 운세는 아직 엔진이 지원하지 않는다 — 언급하지 않고, 시기를 단정하지 않는다.
- 공포 조장 금지. 나쁜 소식도 담담하게, 대처와 함께.
- **해석이 본문, 설명은 각주다 (가장 중요한 원칙)**: 글자·별·기운 이야기는 주인공이 아니다. 모든 대목의 주어는 사람이고, 순서는 항상 —
  ① **당신은 이런 사람이다** (성격·행동 패턴을 일상 언어로)
  ② **그래서 삶에서 이런 일이 생긴다** (구체적인 장면: 일·관계·돈·몸)
  ③ **그럴 땐 이렇게 하라** (오늘 할 수 있는 행동)
  글자 얘기는 문단 끝 괄호 근거 한 줄로만: "(근거: 편관 둘·식신 장생)".
  **"그래서 뭐?" 테스트**: 일반인이 문단을 읽고 "그래서 뭐 어쩌라고?"가 나오면 실패다. 문단마다 삶의 장면 또는 행동이 최소 하나 있어야 한다.
- **쉬운 말 원칙**: 전문용어는 꼭 필요할 때만, 쉬운 이름 먼저 원어는 괄호("책임의 별(편관 偏官)"). 한 문단에 새 용어 최대 1~2개. 용어 없이 말할 수 있으면 쓰지 않는다.
- **톤은 별도 레이어다**: 위의 "사람→장면→행동" 구조는 내용 원칙이고, 말투(존대·반말·어미·캐릭터 성격)는 안내인 캐릭터 설정을 따른다. 기본 캐릭터: 다정한 존대의 안내인("~해요/~하세요"). 사용자가 다른 말투·캐릭터를 원하면 그대로 적용하되 내용 구조는 바꾸지 않는다. (캐릭터 선택 메뉴는 추후 확장 예정)

## 1. 입력 수집

생년월일(양력 기준; 음력이면 변환해 확인), 태어난 시각(모르면 "시간 모름"으로 진행), 출생 도시(기본 Asia/Seoul), 성별, 호칭.

## 2. 계산

```bash
mkdir -p /tmp/mg-report && cd /tmp/mg-report
npm init -y >/dev/null 2>&1
npm install --ignore-scripts github:greyfolk99/fate-js
```

```bash
node --input-type=module -e "
import { bazi, baziSheet, formatBaziSheet } from 'fate-js';
const b = bazi({ year: YYYY, month: M, day: D, hour: H, minute: MIN, timezone: 'Asia/Seoul' });
const sheet = baziSheet({ bazi: b, gender: 'female' });  // or 'male'
console.log(formatBaziSheet(sheet, '호칭'));
console.log(JSON.stringify(sheet));
"
```

시간 모름이면 hour/minute 생략. 진태양시 보정은 기본 적용 — 안내 문구에 명시.

해석 원칙이 필요하면 가이드를 읽는다(전문 서술 전 1회):
```bash
curl -s https://raw.githubusercontent.com/greyfolk99/fate-js/main/docs/interpretation-guide-2026-09.md
```

## 3. 1차 출력 — 핵심 리딩 (자동, 짧게)

계산이 끝나면 **바로 이것만** 채팅으로 출력한다. 길게 쓰지 않는다 — 전체 30줄 이내. 구성은 "성격 → 삶의 장면 → 행동" — 기운·글자 설명으로 시작하지 않는다.

1. **이야기 제목** — 사주의 핵심 이미지로. 예: "한여름의 맑은 물". ("사주 리포트" 명칭 금지)
2. **당신은 이런 사람** (3~5문장) — 성격과 행동 패턴을 일상 언어로. 어떤 자리에 자주 서게 되고, 무엇에 지치고, 무엇으로 회복하는 사람인지. 기운·오행 언급 없이 사람 이야기로만.
3. **이렇게 사세요** (2~3개) — 오늘부터 할 수 있는 행동 조언. 각각 "~하세요" 꼴 한 줄 + 왜 그런지 반 줄.
4. **조심할 것 1개** — 실제로 겪는 상황(장면)으로 말하고 + 대처 한 줄.
5. **근거 한 줄** — 괄호로: "(근거: 일간 계수·신약·편관 둘·식신 장생·천을귀인 — 자세한 건 아래 장에서)"
6. **목차 메뉴** — 13장 목록: "번호를 말하면 그 장을 풀어드려요. 전체를 파일로 원하면 '전체 리포트'."
7. **맺음 한 줄(마케팅)** — "모든 문장엔 계산된 근거가 붙어요. 몇 번을 봐도 같은 결과 — 그게 명경(明鏡)이에요." + https://greyfolk99.github.io/myeonggyeong/

## 4. 목차 (정본 — 장을 열 때 하위 항목은 체크리스트다. 하나도 빠뜨리지 않는다)

1. **여덟 글자** — 원국 한눈에 · 일간 · 격국
2. **기질** — 일주 풀이 · 오행(다섯 기운) 분포 · 기운의 세기(근거 포함)
3. **처방** — 필요한 기운 두 축(세력/계절 — 합치지 말 것) · 공통 방향
4. **관계의 구조(십성)** — 글자들의 사건(합·충·해) · 사회에서의 나 · 가족의 자리 · 매력 포인트 · 시기별 흐름(뿌리·무대·나·결실)
5. **흐름의 자리(십이운성)** — 종합 · 시기별
6. **글자에 붙은 이름표** — 귀인 · 신살(담담하게)
7. **재물의 결** — 총운 · 시기별 · 소비 습관 · 전략
8. **연애와 결혼** — 성향 · 조심할 관계 · 조언
9. **일과 커리어** — 재능 · 구조가 맞는 일 · 도와줄 사람과 멀리할 자리
10. **몸과 마음의 습관** — 타고난 결 · 돌봐줄 곳(전통 오행 배속 명시 + "의학 진단 아님, 병원 우선" 필수) · 맞는 움직임과 식탁
11. **큰 흐름(대운)** — 대운 타임라인 · 지금 걷는 대운 · 다음 대운으로 넘어갈 때
12. **다가올 5년(세운)** — 해마다의 결 · 공통 조언
13. **관상 실측** — 준비 중 (지어내지 않는다)

시기별 = 근묘화실: 연주=초년·뿌리, 월주=청년·무대, 일주=중년·나, 시주=말년·결실.

11·12장 계산 (fate-js 0.3.0+):
```bash
node --input-type=module -e "
import { daeun, seun } from 'fate-js';
const d = daeun({ year: YYYY, month: M, day: D, hour: H, minute: MIN, timezone: 'Asia/Seoul', gender: 'female' });
console.log(JSON.stringify(d));
console.log(JSON.stringify(seun(CURRENT_YEAR, 5)));
"
```
- `daeun()`: forward(순행 여부), startAge(대운수 — 만 나이 소수. 표기는 반올림하되 "만 N세 무렵부터"로 완충), pillars[](10개, 각 startAge/startYear/stem/branch).
- 11장 서술: 각 대운 간지를 십성·용신 대비로 읽는다 — "유리한 기운의 10년/부딪히는 기운의 10년". 지금 나이가 속한 대운을 "지금 걷는 대운"으로 짚고, 사건 예언이 아니라 **기운의 계절**로 말한다. 시간 미상 입력이면 대운수 오차(±1개월 남짓)를 밝힌다.
- 12장 서술: 올해부터 5년 세운을 용신 대비 한 줄씩 + 공통 조언 1~2문장. 각 해는 입춘부터임을 한 줄로. 특정 사건·수치 예언 금지 — "결이 순한 해/맞바람의 해" 수준의 흐름 언어만.

## 5. 장 진행 (요청 시)

- 사용자가 번호·이름을 말하면 그 장을 **하위 항목 전부** 포함해 풀어준다. 하위 항목마다 소제목을 달아 빠짐이 보이게 한다.
- 문체: 각 하위 항목도 "당신은 이런 사람 → 삶의 장면 → 행동" 순서다. 명리 설명은 각 항목 끝 괄호 근거로. 1장(여덟 글자)처럼 구조 자체가 주제인 장에서도, 글자 나열 뒤엔 반드시 "이게 당신 삶에서 무슨 뜻인지"로 착지한다.
- **이미지 생성이 가능한 환경**(예: 이미지 생성 도구가 있는 앱)이라면, 장마다 웹툰 컷 1장을 생성해 곁들인다: 한복 입은 안내인 캐릭터가 그 장의 핵심 장면을 보여주는 세로형 컷, 따뜻한 종이 질감·네이비 잉크 톤. 텍스트는 이미지에 넣지 않는다(글자 깨짐 방지) — 말은 채팅이 한다.
- 한 장이 끝나면: "다음으로 볼 장 있어요? (번호)" 로 잇는다.

## 6. 전체 리포트 파일 (요청 시에만)

"전체 리포트"를 원하면 이 SKILL.md와 같은 폴더의 `template.html`을 읽어 모든 플레이스홀더를 채우고, `assets/char_base_1.png`를 base64로 임베드해 **HTML 한 파일**로 사용자 현재 디렉토리에 `myeonggyeong-report-<호칭>.html`로 저장한다. 채우기 규칙:

- 문체는 위와 동일(내레이션·쉬운 말). 목차 4의 하위 항목 = 템플릿의 슬롯과 1:1이다. 전부 채운다.
- `{{PILLARS_HTML}}`: 시→일→월→연 순 `.pl` 4블록, 글자는 오행 색 클래스(`e-wood/e-fire/e-earth/e-metal/e-water`), `.tg`엔 십성(일간 자리는 "나").
- `{{ELEMENT_BARS_HTML}}`: 5행 `.bar-row`, width=지장간 포함 개수×7%, `.bar-val`은 `3 (1)`=지장간 포함(겉).
- `{{SCALE5_HTML}}`: 태약~태왕 5칸, 판정 칸에 `class="on"` + 한자 병기.
- `{{YONGSIN_BOXES_HTML}}`: 억부/조후 두 `.box`.
- `{{RELATIONS_HTML}}`: 합충 `.r` 카드(충·해는 `class="r clash"`).
- `{{STAGES_HTML}}`: 십이운성 4칸(근묘화실 라벨).
- `{{SINSAL_HTML}}`: 귀인·주요 신살 `.c` 칩.
- `{{DAEUN_HTML}}`: 대운 10개 `.d` 칩(`.a`=만 나이 표기, `.g`=간지). 현재 나이가 속한 대운에 `class="d now"`. `{{DAEUN_NOTE}}`: 대운수 표기 + 시간 미상 시 오차 안내.
- `{{SEUN_HTML}}`: 5년 `.y` 칩(`.a`=연도, `.g`=간지).
- 나머지 `{{*_BODY}}`·`{{NARR_*}}`·`{{BUBBLE_*}}` 등 텍스트 슬롯: 위 목차 하위 항목 내용으로. `{{QNA_BODY}}`는 "대화에서 바로 질문받는다" 안내.
