# 명경(明鏡) 리포트 v0.5

생년월일시 → fate-js로 원국 계산 → 해석 가이드에 따라 살붙이기 → 웹툰형 HTML 한 파일 출력.

## 0. 원칙 (위반 금지)

- 시트에 없는 사실을 지어내지 않는다. 모든 해석 문장은 계산된 팩트에 근거한다.
- 대운·세운·연도별 운세는 아직 엔진이 지원하지 않는다 — 언급하지 않는다. 시기를 단정하지 않는다.
- 관상 파트는 이 버전에 없다 — 리포트 푸터의 예고 한 줄로만 안내한다.
- 공포 조장 금지. 나쁜 소식도 담담하게, 대처와 함께.

## 1. 입력 수집

필요한 것: 생년월일(양력 기준; 음력이면 양력으로 변환해 확인받기), 태어난 시각(모르면 "시간 모름"으로 진행 — 세 기둥 리포트), 출생 도시(타임존 판단용, 기본 Asia/Seoul), 성별, 리포트에 쓸 호칭(이름/닉네임).

## 2. 계산

임시 작업 폴더에서:

```bash
mkdir -p /tmp/mg-report && cd /tmp/mg-report
npm init -y >/dev/null 2>&1
npm install --ignore-scripts github:greyfolk99/fate-js
```

```bash
node --input-type=module -e "
import { bazi, baziSheet, formatBaziSheet } from 'fate-js';
const b = bazi({ year: YYYY, month: M, day: D, hour: H, minute: MIN, timezone: 'Asia/Seoul' });
const sheet = baziSheet({ bazi: b, gender: 'female' });  // or 'male'
console.log(formatBaziSheet(sheet, '호칭'));
console.log(JSON.stringify(sheet));
" > sheet.json
```

- 시간 모름이면 hour/minute 생략 (시주 없이 계산됨).
- 진태양시 보정은 기본 적용됨(시주에만). meta 라인에 "진태양시 보정"을 명시한다.

## 3. 해석 가이드

해석 문장을 쓰기 전에 반드시 가이드를 읽는다:

```bash
curl -s https://raw.githubusercontent.com/greyfolk99/fate-js/main/docs/interpretation-guide-2026-09.md
```

가이드의 대원칙(사실 구속·운명 단정 금지·조언 3층위·유파 비노출·한자 병기 등)과 필드별 지침을 그대로 따른다. 해석이 유파에 따라 갈리는 지점(강약 경계, 용신 등)은 가이드의 경계 표현 규칙대로 "달리 보는 시각이 있다"고 명시한다.

## 4. 리포트 조립

이 SKILL.md와 같은 폴더의 `template.html`을 읽어 플레이스홀더를 채운다. 캐릭터 그림은 같은 폴더 `assets/char_base_1.png`를 base64 data URI로 임베드해 HTML 한 파일로 만든다(외부 참조 없이 단독으로 열리게).

**문체 — 리포트가 아니라 내레이션.** 전체가 한 편의 이야기다: 웹툰의 자막(내레이션 박스)이 장면을 서술하듯 쓴다. "~분석됩니다/~구조입니다"류의 보고서체 금지. 주인공을 소개하고(도입), 글자들이 만드는 장면을 서술하고(전개), 여운으로 맺는다(맺음). 데이터 카드(원국·막대·척도)는 그대로 두되, 글은 전부 이야기의 목소리로. 단, 팩트 구속 원칙은 그대로 — 시적인 문장도 시트의 사실 위에서만.

세 층위의 목소리:
- `{{NARR_*}}` (내레이션 박스): 3인칭 서술자. 장면을 그리듯. 예: "한여름의 아침, 물의 기운을 타고난 사람이 태어났습니다."
- `{{BUBBLE_*}}` (말풍선): 캐릭터가 독자에게 직접 건네는 말. 짧고 다정하게.
- `p.body` (본문): 내레이션의 연장 — 데이터 카드를 이야기로 풀어주는 문단.

매핑 규칙:

- `{{REPORT_TITLE}}`: 사주의 핵심 이미지로 짓는 이야기 제목 + 호칭. 예: `한여름의 맑은 물 — 지우님의 여덟 글자`. "사주 리포트" 같은 명칭 금지.
- `{{META_LINE}}`: `1993년 7월 21일 08:40 · 서울 · 진태양시 보정` 형식. 리포트가 요청자 본인용이 아니면 생년월일 노출 여부를 먼저 확인.
- `{{NARR_INTRO}}`: 도입 내레이션 2~3문장 — 계절·일간의 이미지로 주인공 소개.
- `{{NARR_ELEMENTS}}`: 원국→오행으로 넘어가는 다리 1~2문장 — "글자들을 세어 보면 균형이 보입니다"류.
- `{{NARR_SIPSEONG}}`: 용신→십성으로 넘어가는 다리 1~2문장 — 기운 이야기에서 사람 이야기로 전환.
- `{{NARR_CLOSING}}`: 맺음 내레이션 2~3문장 — 이야기의 여운. 운명 단정·예언 금지, 사실이 남긴 방향만.
- `{{PILLARS_HTML}}`: 시주→일주→월주→연주 순서로 4개 `.pl` 블록. 각 글자는 오행 색 클래스(`e-wood/e-fire/e-earth/e-metal/e-water`)로 감싼다. `.tg`엔 천간·지지의 십성(일간 자리는 "나"). 시주 없으면 3칸 그리드로.
  ```html
  <div class="pl"><div class="lab">시주</div><div class="g"><span class="e-fire">丙</span><br><span class="e-earth">辰</span></div><div class="tg">정재 · 정관</div></div>
  ```
- `{{NOTE_LINE}}`: `일간 계수(癸水) · 편관격(偏官格) · 공망 진사(辰巳)` 형식 (시트의 dayMaster·격국·공망).
- `{{ELEMENT_BARS_HTML}}`: 목화토금수 5행 `.bar-row`. 막대 width = 지장간 포함 개수 × 7%, fill 색은 해당 오행 변수. `.bar-val`은 `3 (2)` = 지장간 포함(겉으로 드러난 수).
  ```html
  <div class="bar-row"><span class="el e-water">수 水</span><div class="bar-track"><div class="bar-fill" style="width:21%;background:var(--water)"></div></div><span class="bar-val">3 (3)</span></div>
  ```
- `{{SCALE5_HTML}}`: 태약/신약/중화/신강/태왕 5칸 `.scale5`, 시트의 강약 판정 칸에 `class="on"`과 한자 병기(예: `신약 身弱`). 판정이 경계면 가이드 규칙대로 본문에서 경계임을 언급.
- `{{YONGSIN_BOXES_HTML}}`: 두 `.box` — 세력의 축(억부 抑扶: 시트 용신 오행들)과 계절의 축(조후 調候: 시트 조후 글자들). 각 `.exp`에 왜 그 기운이 이로운지 한 줄.
- `{{YONGSIN_BODY}}`: 두 축의 관계(일치/충돌)와 공통으로 반가운 방향 2~3문장, 내레이션체로. 두 축은 합치지 않는다.
- `{{ILJU_BODY}}`: 일주(일간+일지) 풀이 2~3문장 — 일주 그림 + 계절 맥락.
- `{{STRENGTH_BODY}}`: 강약 판정 근거를 이야기로 — 득령·득지·득세(ally:foe)를 문장 안에 풀어 쓰고 판정 한자 병기. 경계면 갈린다고 명시.
- `{{SIPSEONG_BODY}}`: 십성 배치가 만드는 인물의 구조 3~5문장.
- `{{RELATIONS_HTML}}`: analysis.relations의 합·충·해·반합을 `.r` 카드로(충·해는 `class="r clash"`). 각 카드: 글자쌍, 관계명(한자 병기), 자리와 한 줄 의미.
- `{{RELATIONS_BODY}}`: 가장 중요한 관계 1~2개의 서사 + 대처 한 줄.
- `{{STAGES_HTML}}`: 십이운성 4칸 `.s` — 자리 라벨은 근묘화실(연=뿌리, 월=무대, 일=나, 시=결실), 값은 한자 병기, `.k`에 한 줄 심상.
- `{{STAGES_BODY}}`: 십이운성이 그리는 흐름 이야기 3~4문장.
- `{{SINSAL_HTML}}`: specialSinsal + twelveSinsal(fromDay 기준 주요만)을 `.c` 칩으로 — 이름 한자 병기 + 자리. 공포 어휘 금지.
- `{{SINSAL_BODY}}`: 귀인 중심 2~3문장, 살(殺)은 담담한 심상으로.
- `{{NARR_LIFE}}`: 6장→7장 다리 내레이션 — 구조 이야기에서 살림살이(재물·사랑·일·몸) 이야기로 전환.

각 장의 세부 항목(전부 채운다 — 비우지 않는다):
- 4장: `{{SOCIAL_BODY}}`(사회에서의 나 — 관성·비겁 구조), `{{FAMILY_BODY}}`(가족의 자리 — 육친 배치: 인성=어머니, 재성=아버지, 관성/재성=배우자, 식상/관성=자녀. 자리와 합충으로 서술), `{{CHARM_BODY}}`(매력 포인트 — 십성·귀인 조합 2~3가지), `{{SIPSEONG_TIMELINE}}`(시기별 — 근묘화실: 연=초년, 월=청년, 일=중년, 시=말년 기둥의 십성으로).
- 5장: `{{STAGES_BODY}}`(종합) + `{{STAGES_TIMELINE}}`(근묘화실 시기별 십이운성 서사).
- 7장: `{{WEALTH_BODY}}`(총운 — 재성 글자·자리, 겉/숨은), `{{WEALTH_TIMELINE}}`(시기별 — 재성이 앉은 기둥의 근묘화실), `{{WEALTH_SPENDING}}`(소비 습관 — 정재/편재 성향+재성 오행), `{{WEALTH_STRATEGY}}`(전략 — 용신 오행의 방식/기신 오행의 방식 대비). 투자 권유·금액 언급 금지.
- 8장: `{{LOVE_BODY}}`(성향 — 배우자성(여=관성, 남=재성) 배치+배우자궁), `{{LOVE_CAUTION}}`(조심할 관계 — 합충이 덧나는 상대 유형), `{{LOVE_ADVICE}}`(조언 — 대처 습관. 시기 단정 금지, 대운 장 열리면 다룬다고 명시 가능).
- 9장: `{{CAREER_TALENT}}`(재능 — 식상·인성·귀인), `{{CAREER_BODY}}`(구조가 맞는 일 — 격국 기반 조건, 직업 단정 대신 조건 서술), `{{CAREER_PEOPLE}}`(도와줄 사람=용신 오행의 십성 얼굴/멀리할 자리=기신의 방식).
- 10장: `{{HEALTH_BODY}}`(타고난 결 — 조후·치우침을 기운의 언어로), `{{HEALTH_CARE}}`(돌봐줄 곳 — 전통 오행 배속(水=신장·방광, 金=폐·호흡, 木=간·근, 火=심·혈, 土=비위) 기준을 명시하고, "의학 진단 아님·병원 우선" 한 줄 필수), `{{HEALTH_HABIT}}`(맞는 움직임·식탁 — 용신/조후 방향의 생활 습관).
- 마무리: `{{QNA_BODY}}` — 대화에서 바로 질문받겠다는 안내. "글자에 있는 만큼만, 근거와 함께" 취지.
- `{{BUBBLE_1~3}}`: 캐릭터 목소리. 짧고 따뜻하게 — 1=주인공 소개 훅, 2=기운에서 처방으로 넘어가는 다리, 3=마무리 한마디(팩트 기반, 빈말 금지).

대운·연운·관상 예고는 템플릿의 고정 문구(곧 열리는 장)로 처리돼 있다 — 내용을 지어 넣지 않는다.

## 5. 출력

작업 폴더가 아닌 사용자 현재 디렉토리에 `myeonggyeong-report-<호칭>.html`로 저장하고, 브라우저로 열어보라고 안내한다. 마지막에 원칙 한 줄: "같은 입력이면 언제 봐도 같은 결과가 나옵니다."
